# SACBM CSR Platform User Guide

## 1. About the platform

The SACBM CSR Platform brings together public impact stories, member contributions, disaster-relief requests, operational reporting, government-priority information, and administration tools.

Use this guide to:

- Explore SACBM's public impact and event information.
- Submit and track social-impact actions as a member.
- Submit and manage disaster-relief requests.
- Review weather, INGD, and government-priority information.
- Build reports from platform data.
- Manage platform content when you are an authorized administrator.

## 2. Access levels

### Public visitors

No sign-in is required to:

- View the public dashboard.
- Browse the impact gallery.
- Search member and company information.
- Browse events and open event details.
- View the Mandela Day campaign page.

### Members

Members use the **Member Section** to identify themselves with their full name and email address. This allows them to submit social-impact actions, share media, and generate member impact reports.

Member access is a simple identification form stored in the current browser. It is not the same as protected administrator authentication. Do not use the member form to share confidential information or to access administrative functions.

### Authorized operations and administrators

The operational dashboard is protected by sign-in. Authorized users can access request management, action management, reporting, weather, INGD, government priorities, the data repository, and the Admin Panel according to their responsibilities.

Only use credentials issued by SACBM. Never share passwords in this document or with other users.

## 3. Public website

### Dashboard

The public dashboard provides a high-level view of SACBM's work, including:

- Summary impact statistics.
- Upcoming events.
- Moments of Impact.
- Links to member, gallery, and campaign content.

Use the navigation bar to return to the dashboard from any public page.

### Impact Gallery

1. Open **Our Impact → Gallery**.
2. Search for a story or contribution.
3. Filter by category or member when needed.
4. Select an item to view its full impact details.

### Per Member

1. Open **Our Impact → Per Member**.
2. Search by company or sector.
3. Select a member to view their profile and impact information.
4. Use the available impact link to view that member's gallery contributions.

### Events

1. Open **Events**.
2. Filter the list by event category if needed.
3. Select an event to open its detail page.
4. Review the date, time, location, description, help needs, attachments, and gallery images.
5. Use the available registration, sharing, or member-help options for that event.

### Mandela Day

The Mandela Day page includes the programme, required items, and a donor-interest form.

To submit interest:

1. Review the requested donation items and quantities.
2. Complete the donor or organization details.
3. Submit the form.
4. Follow the confirmation or email instructions shown after submission.

Confirm donation details with the SACBM team before making arrangements. The page may include event-specific requirements that change over time.

## 4. Member portal

### Enter the member portal

1. Open **Member Section**.
2. Enter your full name.
3. Enter a valid email address.
4. Select **Access Member Portal**.

Your member details are stored locally in the browser so the portal can identify your submissions and reports. If you use another browser or clear local browser data, you may need to enter your details again.

### Submit a social-impact action

1. In the Member Section, select **Submit Action**.
2. Enter the company name and action type.
3. Select the impact category and location.
4. Add the partner organization, if applicable.
5. Enter the number of people impacted.
6. Enter the contribution amount, or choose the option to hide the amount from public impact displays when available.
7. Add a clear description of the activity.
8. Upload supporting photos or media when available.
9. Review the information and submit.

Use accurate locations, quantities, dates, partner names, and impact figures. Do not upload personal information that is not needed to demonstrate the activity.

### Generate a member report

1. Open the Member Section and select **Generate Reports**.
2. Choose whether to include actions and/or media.
3. If actions are included, set both a start date and an end date.
4. Filter by organization or category if needed.
5. Select the media files to include, if applicable.
6. Confirm that the report contains the expected records.
7. Select **Generate Report** and save the downloaded file.

If no records match the filters, broaden the date range or remove a filter and try again.

## 5. Relief requests and operations

### Submit a relief request

Authorized users can open **Submit Social Impact partnerships or Relief Requests** from the operational area.

1. Enter the originator's details and contact email.
2. Enter the affected person's or group's full name.
3. Select the province and, when available, the district.
4. Select the partner organization, if applicable.
5. Choose the help type.
6. Enter the number of people affected.
7. Enter the requested value or list the requested items.
8. If the help type is **Evacuation**, select the evacuation method.
9. If the help type is **Multiple**, add at least one item.
10. If **Other** is selected, provide the custom help type or organization name.
11. Review the form and submit.

New requests begin as **Pending**. After a successful submission, the platform redirects to the requests view.

### Review and update requests

On **Requests**, users can:

- Review the reference number, name, email, originator, location, help type, people affected, value, and status.
- Filter or load additional requests as available.
- Select requests for bulk actions.
- Mark requests as met or return them to pending when authorized.
- Review INGD requests and their related documents.
- Commit to or resolve INGD requests when the workflow requires it.
- Delete requests only when authorized and after confirming the action.

Request statuses are shown as:

- **Pending** — the request still needs attention or fulfillment.
- **Met** — the request has been fulfilled or marked complete.

Verify the request details before changing a status. Status changes affect operational reporting.

### Manage social-impact actions

On **Actions**, authorized users can:

- Review contribution metrics and impact records.
- Filter by category, member, company, date, contribution amount, or people impacted.
- Create a new action.
- Edit an existing action after authorization.
- Delete an action after authorization.
- Add photos and supporting documents.
- Review action status such as pending, in progress, or completed.

Use the edit and delete confirmation steps carefully. Keep descriptions factual and use consistent category and location values.

## 6. Weather, INGD, and government priorities

### Weather

Open **Weather** to review forecasts by city or region and regional alerts. Check the selected location before using weather information for operational decisions. Where live weather data is unavailable, review the message shown by the platform and confirm critical conditions through an approved source.

### INGD Dashboard

The **INGD Dashboard** provides a focused view of INGD-related requests and supports request status, commitment, and resolution workflows. Use the dashboard tabs to switch between the overall view and requests.

### Government Priorities

Open **Government Priorities** to review humanitarian priority categories and supporting documents, including food, water treatment, sanitation, seeds, construction materials, and shelter or tool kits.

Use the current supporting documents rather than relying on downloaded copies that may be out of date.

## 7. Reports

The **Reports** page lets authorized users combine platform information into a report.

1. Choose the data sources to include:
   - Social-impact actions.
   - Relief requests.
   - Government priorities.
   - Media and supporting documents.
2. Expand the relevant filter section.
3. Apply submitter, category, help-type, date, originator, or priority filters.
4. Select the media files or priority items to include.
5. Review the selected data.
6. Generate and download the report.

Use a clear reporting period and record the filters used when sharing a report. If the result is empty, remove or broaden the filters before generating again.

## 8. Admin Panel

The **Admin Panel** is for authorized administrators and managers. It may include the following management areas:

- Relief requests.
- INGD requests and activation settings.
- Events, event images, galleries, help needs, and attachments.
- Carousel and Moments of Impact images.
- Government-priority, INGD, action, and relief-request documents.
- Member profiles and member images.
- Approved member access.
- Users and roles.
- Connectivity and repository settings.
- Mandela Day donation claims.

When publishing or changing content:

1. Confirm that you are working in the correct management section.
2. Check names, dates, locations, quantities, and descriptions.
3. Preview or review uploaded media and documents.
4. Save changes only after checking the full record.
5. Remove obsolete content only when you are certain it is no longer needed.

### Sign in and sign out

1. Open **Admin Panel Login**.
2. Enter the email address issued to you by SACBM.
3. Enter your password.
4. Select **Sign In**.
5. When finished, select **Logout** in the top-right corner.

Use **Back to Site** to open the public website without ending the administrative session. Always log out on shared or public computers.

## 9. Good data practices

- Use one consistent company or member name for related submissions.
- Enter amounts in MZN and check the value before submitting.
- Use the most specific province and district available.
- Avoid duplicate requests and duplicate action records.
- Add enough description for another operator to understand what happened.
- Upload only relevant, authorized photos and documents.
- Do not include unnecessary identity, medical, financial, or contact information in descriptions or media.
- Confirm important operational decisions with the responsible SACBM team.
- Treat downloaded reports and documents as potentially sensitive.

## 10. Troubleshooting

### I cannot access the member portal

Check that both the full name and a valid email address are entered. Correct any validation message and submit again.

### My member information is not remembered

Member access is stored in the current browser. Re-enter your name and email if browser storage was cleared, if you changed browsers, or if you are using a different device.

### A relief request will not submit

Check all required fields. Also confirm that:

- A help type is selected.
- An evacuation method is selected for evacuation requests.
- At least one item is listed for multiple-item requests.
- A value is entered for non-multiple requests.
- A custom value is entered when **Other** is selected.

### A report is empty

Broaden the date range, remove an unnecessary filter, or confirm that the selected data source contains records.

### I cannot sign in to the Admin Panel

Confirm that you are using an authorized SACBM account and that the email and password are entered correctly. If the problem continues, contact the platform administrator rather than sharing credentials.

### I need support

Contact the SACBM platform administrator or the support contact published in the platform footer. Include the page you were using, the action you attempted, and the visible error message. Do not send passwords or sensitive personal data in a support request.
